# Contextual Relevance Check and Enhancement of Image Captions using BLIP

An AI-based system that checks the contextual relevance of a user-provided image caption and generates an enhanced caption using BLIP.

## 🎯 Objectives

- Generate captions from uploaded images.
- Check the relevance of user-provided captions.
- Calculate a contextual relevance score.
- Generate an enhanced caption using BLIP.

## 🛠️ Technologies Used

- React.js
- FastAPI
- Python
- PyTorch
- BLIP
- Sentence-BERT (SBERT)

## 🔄 Workflow

1. User uploads an image and optionally provides a caption.
2. React.js sends the input to the FastAPI backend.
3. BLIP analyzes the image and generates an AI-based caption.
4. The user caption is compared with the generated caption.
5. A contextual relevance score is calculated.
6. The system displays the relevance score and enhanced caption.

## 📌 Expected Output

- **Relevance Score**
- **AI-Generated / Enhanced Caption**
